### [Axiom Trade Testbed](https://axiom-trade-testbed.netlify.app) — Trading Strategy Builder & Backtester

Fully client-side Angular app — no backend, no database. Compose a no-code trading strategy from 80+ technical indicators, run a bar-by-bar backtest against live Binance or Alpaca market data, and inspect results via an equity curve, drawdown chart, trade log, and stats panel. Includes a financial glossary with 117 terms and KaTeX-rendered formulas.

`Angular 21` `TypeScript` `Lightweight Charts v5` `RxJS` `Binance WS` `Alpaca API` `KaTeX`

[(https://axiom-trade-testbed.netlify.app](https://axiom-trade-testbed.netlify.app)
